# 指標 `&` `*`

## 本集目標

認識指標：用 `&` 取得變數的位址，用 `*` 透過位址讀寫原本的變數。

## 正文

先看一個第 2 章就會遇到的問題：

```go
package main

import "fmt"

func addOne(n int) {
	n = n + 1
}

func main() {
	x := 10
	addOne(x)
	fmt.Println(x)
}
```

執行結果：

```text
10
```

`x` 沒有變成 11。原因是呼叫函式時，Go 會把 `x` 的值**複製**一份給參數 `n`。函式裡改的是那份複本，原本的 `x` 完全不受影響。

那如果真的想讓函式改到 `x` 呢？我們需要告訴函式「`x` 住在哪裡」。

### 位址與 `&`

每個變數都存放在記憶體裡的某個位置，這個位置叫做**位址**。在變數前面加 `&`，就能拿到它的位址：

```go
package main

import "fmt"

func main() {
	x := 10
	p := &x
	fmt.Println(*p)
}
```

執行結果：

```text
10
```

- `&x` 讀作「`x` 的位址」。
- 存放位址的變數叫做**指標**（pointer）。`p` 就是一個指標，它指向 `x`。
- `p` 的型別寫成 `*int`，意思是「指向 `int` 的指標」。

位址本身是一串像 `0xc000012345` 的數字，每次執行都可能不一樣，印出來沒什麼意義。我們真正在意的是它指向的那個值。

### 用 `*` 讀寫指向的值

在指標前面加 `*`，就能透過位址找到原本的變數，這個動作叫做**解參考**（dereference）。`*p` 不只能讀，還能寫：

```go
package main

import "fmt"

func main() {
	x := 10
	p := &x
	*p = 20
	fmt.Println(x)
	x = 30
	fmt.Println(*p)
}
```

執行結果：

```text
20
30
```

`*p = 20` 改的就是 `x` 本身。反過來，直接改 `x` 之後，從 `*p` 讀到的也是新的值。因為 `p` 和 `x` 指的是同一塊記憶體。

`*` 出現在兩種地方，意思不同，別搞混：

- 寫在**型別**前面，例如 `*int`：表示「指向 `int` 的指標」這個型別。
- 寫在**指標變數**前面，例如 `*p`：表示「`p` 指向的那個值」。

### 讓函式修改呼叫者的變數

回到開頭的問題。把參數改成指標，函式就能改到原本的變數：

```go
package main

import "fmt"

func addOne(n *int) {
	*n = *n + 1
}

func main() {
	x := 10
	addOne(&x)
	fmt.Println(x)
}
```

執行結果：

```text
11
```

這次傳進去的是 `&x`，也就是 `x` 的位址。Go 一樣會複製參數，但複製的是「位址」，複本指向的還是同一個 `x`。函式裡的 `*n = *n + 1` 透過位址改到了 `x`。

## 重點整理

- 呼叫函式時參數是複製的，函式改參數不會影響呼叫者的變數。
- `&x` 取得 `x` 的位址；存放位址的變數叫指標，型別寫成 `*int` 這種形式。
- `*p` 透過指標讀寫原本的值（解參考）。
- 參數用指標，函式就能修改呼叫者的變數。
