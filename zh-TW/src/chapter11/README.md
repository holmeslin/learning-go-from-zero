# 進階語言功能

到這裡，你已經學完 Go 日常寫程式會用到的語法，也會用 goroutine 和 context 處理並行。這一章收集了一些比較少直接寫、但讀別人的程式碼或標準函式庫時一定會碰到的功能：在執行期間檢查型別的 `reflect`、型別別名、把檔案編進執行檔的 `//go:embed`、依平台或條件挑選檔案的 build tags、自動產生程式碼的 `//go:generate`，以及 `unsafe`、cgo、`runtime.AddCleanup` 和 `weak` 這些貼近底層的工具。

這些功能有個共同點：威力大、但用錯的代價也大。所以每一集除了教怎麼用，也會說清楚**什麼時候不該用**。大部分情況下，前面學過的介面、泛型和一般程式碼就是更好的選擇；把這章當成「認得它們、知道它們的界線」就夠了。
