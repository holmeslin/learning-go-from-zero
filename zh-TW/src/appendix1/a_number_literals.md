# 數字字面值

## 本集目標

認識 Go 寫數字的各種方式：底線分隔、十六進位、八進位、二進位與科學記號。

## 正文

直接寫在程式碼裡的值，例如 `42`、`"hello"`，叫做**字面值**。整數到目前為止我們都用十進位來寫，其實 Go 還提供了好幾種寫法，讓數字更好讀，或更貼近它的用途。

### 用底線讓大數字好讀

`1000000` 是一百萬還是十萬？數零數到眼花。Go 允許在數字中間加底線 `_` 當分隔：

```go
package main

import "fmt"

func main() {
	population := 23_400_000
	price := 1_000_000
	fmt.Println(population)
	fmt.Println(price)
}
```

執行結果：

```text
23400000
1000000
```

底線只是給人看的，編譯器會直接忽略它，印出來的值完全一樣。底線只能放在兩個數字之間，不能放在開頭或結尾，也不能連續寫兩個。

### 十六進位、八進位、二進位

在數字前面加上前綴，就能用其他進位來寫：

| 前綴 | 進位 | 例子 | 十進位的值 |
| --- | --- | --- | --- |
| `0x` | 十六進位 | `0xFF` | 255 |
| `0o` | 八進位 | `0o755` | 493 |
| `0b` | 二進位 | `0b1010` | 10 |

```go
package main

import "fmt"

func main() {
	color := 0xFF8800
	perm := 0o755
	flags := 0b1010_0001
	fmt.Println(color)
	fmt.Println(perm)
	fmt.Println(flags)
}
```

執行結果：

```text
16746496
493
161
```

不管用哪種進位寫，存進變數的都是同一個整數，`fmt.Println` 一律用十進位印出來。進位只是「寫法」，不是另一種型別。

什麼時候會用到？顏色碼習慣寫成十六進位，檔案權限習慣寫成八進位，一個一個開關的旗標用二進位最清楚。底線也可以搭配這些前綴一起用，像上面的 `0b1010_0001`。

你可能會在舊程式碼看到 `0755` 這種只有一個 `0` 開頭的寫法，它也是八進位。這很容易被誤看成十進位的 755，所以新寫的程式請用 `0o755`，意思一目了然。

### 科學記號

很大或很小的小數，可以用 `e` 表示「乘以 10 的幾次方」：

```go
package main

import "fmt"

func main() {
	million := 1e6
	tiny := 2.5e-3
	light := 3e8
	fmt.Println(million)
	fmt.Println(tiny)
	fmt.Println(light)
}
```

執行結果：

```text
1e+06
0.0025
3e+08
```

`1e6` 是 1 × 10⁶，也就是一百萬；`2.5e-3` 是 2.5 × 10⁻³，也就是 0.0025。

要注意，用 `e` 寫的字面值是**浮點數**，所以 `million` 的型別是 `float64`，不是 `int`。`fmt.Println` 印很大的浮點數時，也會自動改用科學記號。如果你需要的是整數，就直接寫 `1_000_000`。

## 重點整理

- 數字中間可以加 `_` 分隔，例如 `1_000_000`，只是為了好讀，不影響值。
- `0x` 是十六進位、`0o` 是八進位、`0b` 是二進位；存進去的都是同一個整數。
- 八進位請寫 `0o755`，不要寫容易誤會的 `0755`。
- `1e6`、`2.5e-3` 是科學記號，寫出來的是浮點數。
