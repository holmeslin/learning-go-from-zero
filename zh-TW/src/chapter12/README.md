# 進階標準庫

Go 的標準庫很大，而且品質很好，很多別的語言要裝第三方套件才做得到的事，Go 直接內建。這一章挑出寫實際程式時最常用到的幾個：讀寫資料的 `io` 與 `bufio`、操作檔案與目錄的 `os`、`path/filepath`、`io/fs`，處理文字的 `strings.Builder` 與 `bytes`，還有時間、JSON、日誌、亂數和 UUID。

這一章的每一集都很實用。學完之後，你就有能力寫出讀檔、整理資料、輸出 JSON、記錄日誌的程式，接下來第 13～15 章的 CLI 工具、Web 服務與資料庫實戰，都會大量用到這裡的東西。其中 `encoding/json/v2` 和 `uuid` 是 Go 1.27 才正式加入的新套件。
