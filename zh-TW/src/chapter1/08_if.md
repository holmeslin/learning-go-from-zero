# `if`

## 本集目標

用 `if` 讓程式依照條件，決定要不要執行某段程式碼。

## 正文

到目前為止，我們寫的程式都是從第一行乖乖執行到最後一行。但真正有用的程式要會「判斷」：如果某件事成立，就做某件事。

這就是 `if` 的工作。

### 基本用法

```go
package main

import "fmt"

func main() {
	x := 7
	if x > 3 {
		fmt.Println("大於 3")
	}
}
```

執行結果：

```text
大於 3
```

`if` 後面接一個條件，這裡是 `x > 3`。上一集學過，比較運算子算出來的結果是 `true` 或 `false`。`x` 是 7，7 大於 3，條件是 `true`，所以大括號 `{}` 裡面的程式碼就會被執行。

### 條件不成立的話呢？

把 `x` 改成 1 試試看：

```go
package main

import "fmt"

func main() {
	x := 1
	if x > 3 {
		fmt.Println("大於 3")
	}
	fmt.Println("程式結束")
}
```

執行結果：

```text
程式結束
```

1 不大於 3，條件是 `false`，大括號裡的程式碼整段被跳過。不過 `if` 結束之後的程式碼不受影響，照樣會執行，所以還是會印出「程式結束」。

### 兩個 Go 的小規矩

第一，條件**不用**加小括號。你可能在別的地方看過 `if (x > 3)` 這種寫法，在 Go 裡雖然也能編譯，但存檔時 `gofmt` 會把多餘的小括號拿掉，大家都寫成 `if x > 3`。

第二，大括號**一定要寫**，而且左大括號 `{` 必須跟 `if` 放在同一行。就算大括號裡只有一行程式碼也一樣。下面這樣寫是不行的：

```go,compile_fail
package main

import "fmt"

func main() {
	x := 7
	if x > 3
	{
		fmt.Println("大於 3")
	}
}
```

Go 會直接拒絕編譯。這種「只有一種寫法」的規矩，讓每個人寫出來的 Go 程式看起來都差不多，讀別人的程式碼時會輕鬆很多。

## 重點整理

- `if` 後面接條件，條件為 `true` 就執行大括號裡的程式碼，為 `false` 就整段跳過。
- `if` 結束後的程式碼不管條件如何都會繼續執行。
- 條件不用加小括號；大括號一定要寫，且 `{` 要和 `if` 同一行。
