# 註解

## 本集目標

學會在程式碼裡寫註解，留下給人看的說明。

## 正文

程式碼是寫給電腦執行的，但也是寫給人看的，包括幾個月後的你自己。**註解**就是寫在程式碼裡、電腦會完全忽略的文字，專門用來說明。

### 單行註解 `//`

從 `//` 開始到這一行結尾，都是註解：

```go
package main

import "fmt"

func main() {
	// 印出打招呼的話
	fmt.Println("你好")

	price := 100 // 單位是元
	fmt.Println(price)
}
```

執行結果：

```text
你好
100
```

註解可以自己佔一整行，也可以放在程式碼的後面。不管放哪裡，執行結果都不受影響。

### 多行註解 `/* */`

要寫很多行的時候，可以用 `/*` 開始、`*/` 結束，中間全部都是註解：

```go
package main

import "fmt"

func main() {
	/*
		這支程式會印出一個數字。
		這段文字都是註解。
	*/
	fmt.Println(1)
}
```

執行結果：

```text
1
```

不過 Go 的程式碼裡大多用 `//`，就算是好幾行，也習慣每行都加 `//`。

### 暫時停用一行程式碼

註解還有一個好用的地方：在一行程式碼前面加上 `//`，就能讓它暫時不執行，不用真的把它刪掉。

```go
package main

import "fmt"

func main() {
	fmt.Println("第一行")
	// fmt.Println("第二行")
	fmt.Println("第三行")
}
```

執行結果：

```text
第一行
第三行
```

在 VS Code 裡，選取幾行之後按 `Ctrl` + `/`（macOS 是 `Cmd` + `/`），就能一次加上或拿掉 `//`。

## 重點整理

- 註解是給人看的說明，電腦執行時會忽略。
- `//` 到行尾是單行註解；`/*` 到 `*/` 之間是多行註解，Go 習慣多用 `//`。
- 在程式碼前加 `//` 可以暫時停用它。
