# 作用域

## 本集目標

知道本集的區域變數，從宣告結束後到所在的那對大括號結束，才能使用。

## 正文

上一集我們在 `if` 的大括號裡寫程式碼。如果在大括號**裡面**建立一個變數，在外面還能用嗎？

### 大括號裡的變數，出了大括號就不見了

```go,compile_fail
package main

import "fmt"

func main() {
	x := 7
	if x > 3 {
		message := "大於 3"
		fmt.Println(message)
	}
	fmt.Println(message)
}
```

這支程式無法編譯，Go 會告訴你：

```text
./main.go:11:14: undefined: message
```

`undefined` 是「沒有定義」的意思。`message` 是在 `if` 的大括號裡建立的，從宣告結束後，到那對大括號結束都能使用；`if` 結束之後就不能再用，所以第 11 行找不到它。

一個變數「能被使用的範圍」，就叫做它的**作用域**。本集這種在大括號裡建立的變數叫做**區域變數**。判斷方法是：**從宣告結束後開始，往外找最近的一對大括號，到那對大括號結束為止。** 即使在同一對大括號裡，也不能在宣告前就使用它。

### 外面的變數，裡面可以用

反過來就沒問題。在外層建立的變數，裡層的大括號可以使用：

```go
package main

import "fmt"

func main() {
	x := 7
	message := "大於 3"
	if x > 3 {
		fmt.Println(message)
	}
	fmt.Println("x 是", x)
}
```

執行結果：

```text
大於 3
x 是 7
```

`x` 和 `message` 是在 `func main()` 的大括號裡建立的，所以各自從宣告結束後，到 `main` 的大括號結束都能用，包括裡面的 `if` 區塊。

### 為什麼要這樣設計？

只在某一小段用到的變數，就把它放在那一小段裡。這樣出了大括號之後，就不用擔心誤用到它，也不會和別的地方的變數搞混。

## 重點整理

- 本集的區域變數，作用域從宣告結束後開始，到所在的那對大括號結束為止；宣告前還不能用。
- 在大括號裡建立的變數，出了大括號就不能用了，會出現 `undefined` 編譯錯誤。
- 外層已經宣告的變數，裡層的大括號可以使用。
