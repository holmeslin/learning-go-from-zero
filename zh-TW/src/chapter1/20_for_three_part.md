# 三段式 `for`

## 本集目標

用三段式 `for` 把「建立計數變數、檢查條件、更新變數」寫在同一行。

## 正文

上一集數到 3 的程式，跟計數有關的程式碼分散在三個地方：

```go,ignore
count := 1         // 1. 一開始建立變數
for count <= 3 {   // 2. 每圈檢查條件
	...
	count++        // 3. 每圈最後更新變數
}
```

這種「從幾數到幾」的迴圈太常用了，所以 Go 讓我們把這三件事寫在 `for` 的同一行。

### 三段式寫法

```go
package main

import "fmt"

func main() {
	for i := 1; i <= 3; i++ {
		fmt.Println("第", i, "次")
	}
	fmt.Println("結束")
}
```

執行結果：

```text
第 1 次
第 2 次
第 3 次
結束
```

`for` 後面用兩個分號 `;` 分成三段：

1. `i := 1`：**初始化**，迴圈開始前只執行一次。
2. `i <= 3`：**條件**，每一圈開始前檢查，成立才執行這一圈。
3. `i++`：**更新**，每一圈的大括號執行完之後執行。

計數用的變數習慣取名叫 `i`。

### `i` 只在迴圈裡有效

`i` 是在 `for` 這一行建立的，它的作用域就是這個迴圈。迴圈結束後就不能再用 `i` 了。這正好符合第 9 集學的：只在一小段用到的變數，就讓它只活在那一小段裡。

### 從 0 開始，用 `<`

程式裡很常從 0 開始數。要重複 5 次，常見的寫法是：

```go
package main

import "fmt"

func main() {
	for i := 0; i < 5; i++ {
		fmt.Println(i)
	}
}
```

執行結果：

```text
0
1
2
3
4
```

`i` 從 0 跑到 4，剛好 5 次。「從 0 開始、用 `<`」這個組合以後會一直看到，先記起來。

### 不一定要加 1

更新那一段可以寫任何賦值，例如每次加 2，或是倒著數：

```go
package main

import "fmt"

func main() {
	for i := 10; i > 0; i -= 3 {
		fmt.Println(i)
	}
}
```

執行結果：

```text
10
7
4
1
```

### 例子：加總

算出 1 加到 100 的總和：

```go
package main

import "fmt"

func main() {
	sum := 0
	for i := 1; i <= 100; i++ {
		sum += i
	}
	fmt.Println(sum)
}
```

執行結果：

```text
5050
```

`sum` 要建立在迴圈**外面**，因為迴圈結束後還要印出它。

## 重點整理

- 三段式 `for`：`for 初始化; 條件; 更新 { ... }`，三段用分號隔開。
- 初始化只執行一次；條件在每圈開始前檢查；更新在每圈結束後執行。
- 在初始化建立的變數只在迴圈裡有效。
- 重複 n 次的常見寫法：`for i := 0; i < n; i++`。
