# 算術運算子

## 本集目標

用 `+`、`-`、`*`、`/`、`%` 讓程式幫我們做加減乘除。

## 正文

電腦最擅長的事情之一就是算數學。Go 的算術運算子有五個：

| 運算子 | 意思 |
| --- | --- |
| `+` | 加 |
| `-` | 減 |
| `*` | 乘 |
| `/` | 除 |
| `%` | 取餘數 |

乘號是星號 `*`，不是 `x`；除號是斜線 `/`。

### 基本四則運算

```go
package main

import "fmt"

func main() {
	fmt.Println(7 + 2)
	fmt.Println(7 - 2)
	fmt.Println(7 * 2)
	fmt.Println(8 / 2)
}
```

執行結果：

```text
9
5
14
4
```

變數也可以拿來算，算出來的結果還可以再存進新的變數：

```go
package main

import "fmt"

func main() {
	apple := 30
	banana := 25
	total := apple + banana
	fmt.Println("總共", total, "元")
}
```

執行結果：

```text
總共 55 元
```

### 整數相除會捨去小數

試試看 `7 / 2`：

```go
package main

import "fmt"

func main() {
	fmt.Println(7 / 2)
	fmt.Println(7.0 / 2)
}
```

執行結果：

```text
3
3.5
```

`7 / 2` 印出的是 `3` 而不是 `3.5`！因為 7 和 2 都是整數，整數相除的結果也是整數，小數部分會直接丟掉。只要其中一邊寫成有小數點的數字（例如 `7.0`），就會得到 `3.5`。這件事在第 25 集會再詳細說明。

### 取餘數 `%`

`%` 算的是「除完之後剩下多少」：

```go
package main

import "fmt"

func main() {
	fmt.Println(7 % 2)
	fmt.Println(10 % 3)
	fmt.Println(9 % 3)
}
```

執行結果：

```text
1
1
0
```

7 除以 2 等於 3 餘 1，所以 `7 % 2` 是 1。`%` 很常用來判斷一個數能不能被整除：餘數是 0 就代表整除。

## 重點整理

- 算術運算子有 `+`、`-`、`*`、`/`、`%`，數字和變數都可以拿來算。
- 兩個整數相除，結果還是整數，小數部分會被丟掉。
- `%` 算的是除完之後的餘數，餘數為 0 代表整除。
