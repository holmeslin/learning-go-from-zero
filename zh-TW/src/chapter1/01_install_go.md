# 安裝 Go

## 本集目標

在自己的電腦上裝好 Go 和編輯器，並確認安裝成功。

## 正文

寫 Go 程式需要兩樣東西：一個是 **Go 工具**，負責把我們寫的程式碼變成電腦能執行的程式；另一個是**編輯器**，讓我們打字寫程式碼。

### 下載 Go

打開 Go 的官方下載頁面：<https://go.dev/dl/>

頁面上會依照作業系統列出安裝檔：

- **macOS**：下載 `.pkg` 檔，點兩下照著畫面按「繼續」就好。注意要選和你的電腦相符的版本（Apple 晶片選 ARM64，Intel 晶片選 x86-64）。
- **Windows**：下載 `.msi` 檔，點兩下照著畫面安裝。
- **Linux**：下載 `.tar.gz` 檔，下載頁面底下有安裝步驟可以照著做。

本書以 Go 1.27 為準，請下載 1.27 開頭的版本（或更新的版本）。

### 確認安裝成功

安裝完之後，打開**終端機**（macOS 叫「終端機」，Windows 可以用「命令提示字元」或 PowerShell）。終端機是一個用打字下指令的視窗，之後我們會常常用到它。

如果終端機在安裝前就已經開著，請把它關掉再重新打開。然後輸入下面這行，按 Enter：

```bash
go version
```

如果看到類似這樣的一行文字，就代表裝好了：

```text
go version go1.27.0 darwin/arm64
```

重點是有出現 `go1.27` 開頭的版本號。最後一段會依照你的作業系統而不同，例如 Windows 會是 `windows/amd64`，不用在意。

如果出現「找不到指令」之類的訊息，通常是終端機沒有重開，或是安裝沒有完成，重新開一次終端機或重新安裝看看。

### 安裝編輯器

程式碼其實就是純文字，用什麼編輯器都可以寫。本書推薦 **VS Code**，免費而且對 Go 支援很好：

1. 到 <https://code.visualstudio.com/> 下載並安裝 VS Code。
2. 打開 VS Code，在左側的擴充功能（Extensions）裡搜尋 `Go`，安裝由 Go Team at Google 發布的那一個。

裝好這個擴充套件後，存檔時它會自動幫你把程式碼排整齊，打錯字時也會畫紅線提醒你。

## 重點整理

- 到 <https://go.dev/dl/> 下載符合自己作業系統的 Go 安裝檔。
- 在終端機輸入 `go version`，看到 `go1.27` 開頭的版本號就是安裝成功。
- 推薦使用 VS Code 加上 Go 擴充套件來寫程式。
