# 運算子優先順序

## 本集目標

知道一個算式裡有好幾個運算子時，Go 會先算哪一個，並學會用小括號改變順序。

## 正文

### 先乘除，後加減

猜猜看下面會印出什麼？

```go
package main

import "fmt"

func main() {
	fmt.Println(2 + 3*4)
}
```

執行結果：

```text
14
```

答案是 14，不是 20。跟數學課學的一樣：**先乘除，後加減**。Go 會先算 `3*4` 得到 12，再加 2。

`*`、`/`、`%` 是同一組，優先順序比 `+`、`-` 高。同一組的運算子排在一起時，從左邊算到右邊：

```go
package main

import "fmt"

func main() {
	fmt.Println(10 - 3 - 2)
	fmt.Println(12 / 2 * 3)
}
```

執行結果：

```text
5
18
```

`10 - 3 - 2` 是先算 `10 - 3` 得 7，再減 2 得 5。`12 / 2 * 3` 是先算 `12 / 2` 得 6，再乘 3 得 18。

你可能注意到 `3*4` 沒有空格，`10 - 3` 卻有。這是 `gofmt` 自動排的：它會把優先順序高的部分靠緊一點，讓你一眼看出哪裡先算。

### 用小括號改變順序

想先算加法，就用小括號 `()` 把它包起來：

```go
package main

import "fmt"

func main() {
	fmt.Println((2 + 3) * 4)
}
```

執行結果：

```text
20
```

小括號裡的永遠最先算。

### 看不確定就加括號

來算三科的平均分數：

```go
package main

import "fmt"

func main() {
	math := 80
	english := 70
	science := 90
	average := (math + english + science) / 3
	fmt.Println("平均", average, "分")
}
```

執行結果：

```text
平均 80 分
```

如果忘了加括號，寫成 `math + english + science / 3`，就只有 `science` 會被除以 3，答案完全不對。所以只要你自己看到算式會猶豫，就加上小括號，讓意思一目了然。

## 重點整理

- 先乘除（`*`、`/`、`%`），後加減（`+`、`-`）。
- 優先順序相同時，從左算到右。
- 小括號裡的最先算；不確定順序時就加括號。
