# `else if`

## 本集目標

用 `else if` 處理兩種以上的情況。

## 正文

`if` ... `else` 是二選一。但如果情況不只兩種呢？例如把分數分成「優秀」「及格」「不及格」三級。

### 一連串的條件

```go
package main

import "fmt"

func main() {
	score := 75
	if score >= 90 {
		fmt.Println("優秀")
	} else if score >= 60 {
		fmt.Println("及格")
	} else {
		fmt.Println("不及格")
	}
}
```

執行結果：

```text
及格
```

Go 會**從上往下**一個一個檢查條件：

1. `score >= 90`？75 不到 90，`false`，跳過。
2. `score >= 60`？75 大於等於 60，`true`，印出「及格」。
3. 已經找到成立的條件了，後面的 `else` 不會再看。

`else if` 可以接很多個。只要有一個條件成立，就執行它那一段，然後整串結束。全部都不成立的話，才會執行最後的 `else`。最後的 `else` 也可以不寫，那樣全部不成立時就什麼都不做。

### 順序很重要

因為是從上往下檢查，**第一個**成立的條件會被選中。看看把順序寫反會怎樣：

```go
package main

import "fmt"

func main() {
	score := 95
	if score >= 60 {
		fmt.Println("及格")
	} else if score >= 90 {
		fmt.Println("優秀")
	}
}
```

執行結果：

```text
及格
```

95 分應該是「優秀」，卻印出「及格」。因為 `score >= 60` 先被檢查，而且已經成立了，後面的 `score >= 90` 根本沒機會被看到。

範圍有重疊的時候，要把**最嚴格**的條件放在最前面。

## 重點整理

- `else if` 可以接在 `if` 後面，處理更多種情況，可以接很多個。
- 條件從上往下檢查，執行第一個成立的那一段後，整串就結束。
- 全部不成立時才執行最後的 `else`；`else` 可以省略。
- 條件範圍有重疊時，要把最嚴格的條件放前面。
