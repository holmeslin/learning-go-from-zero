# 綜合練習

## 本集目標

把到目前為止學到的東西組合起來，從頭寫一支完整的小程式。

## 正文

我們已經學會了變數、算術、比較、`if` / `else if` / `else`、邏輯運算子、讀取輸入和轉換整數。這些加起來，已經足夠寫出一支有用的小程式了。

### 題目：穿衣建議

寫一支程式：

1. 請使用者輸入今天的氣溫（攝氏，整數）。
2. 輸入的不是整數，就印出「請輸入整數」並結束。
3. 依照氣溫給建議：
   - 低於 15 度：「很冷，穿外套」
   - 15 到 25 度：「涼爽，穿長袖」
   - 高於 25 度：「很熱，穿短袖」
4. 氣溫低於 -50 或高於 60 度時，印出「這個溫度不太合理」。

建議先自己試著寫寫看，再往下看參考答案。

### 參考答案

```go,stdin=28
package main

import (
	"bufio"
	"fmt"
	"os"
	"strconv"
)

func main() {
	scanner := bufio.NewScanner(os.Stdin)
	fmt.Println("請輸入今天的氣溫：")
	scanner.Scan()
	line := scanner.Text()
	temp, err := strconv.Atoi(line)
	if err != nil {
		fmt.Println("請輸入整數")
		return
	}

	// 先排除不合理的溫度
	if temp < -50 || temp > 60 {
		fmt.Println("這個溫度不太合理")
	} else if temp < 15 {
		fmt.Println(temp, "度，很冷，穿外套")
	} else if temp <= 25 {
		fmt.Println(temp, "度，涼爽，穿長袖")
	} else {
		fmt.Println(temp, "度，很熱，穿短袖")
	}
}
```

輸入 `28`，程式印出：

```text
請輸入今天的氣溫：
28 度，很熱，穿短袖
```

### 想一想

- 為什麼「不太合理」的檢查要放在最前面？回想第 11 集：條件是從上往下檢查的。如果把它移到 `temp < 15` 的後面，輸入 `-60` 會怎樣？-60 小於 15，會先被 `temp < 15` 攔下來，印出「很冷，穿外套」，根本輪不到「不太合理」的檢查。
- `temp <= 25` 這個條件為什麼不用寫成 `temp >= 15 && temp <= 25`？因為能走到這裡，代表前面的 `temp < 15` 已經不成立，`temp` 一定大於等於 15 了。

### 自己試試看

用不同的輸入多跑幾次，確認每一種情況都對：`10`、`15`、`25`、`26`、`-60`、`abc`。特別是剛好在邊界上的 `15` 和 `25`，最容易寫錯。

## 重點整理

- 寫程式前先把題目拆成步驟：讀輸入、轉換、檢查錯誤、判斷、輸出。
- 用 `if` / `else if` / `else` 處理多種情況時，要注意條件的順序。
- 測試時要特別試邊界值和錯誤的輸入。
