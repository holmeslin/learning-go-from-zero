# 巢狀迴圈

## 本集目標

在迴圈裡面再放一個迴圈，處理「兩層」的重複。

## 正文

迴圈的大括號裡可以放任何程式碼，當然也包括另一個迴圈。迴圈裡面還有迴圈，叫做**巢狀迴圈**。

### 外層跑一圈，內層跑完整一輪

```go
package main

import "fmt"

func main() {
	for i := 1; i <= 2; i++ {
		for j := 1; j <= 3; j++ {
			fmt.Println("i =", i, "j =", j)
		}
	}
}
```

執行結果：

```text
i = 1 j = 1
i = 1 j = 2
i = 1 j = 3
i = 2 j = 1
i = 2 j = 2
i = 2 j = 3
```

觀察輸出：外層的 `i` 每跑**一圈**，內層的 `j` 就從 1 跑到 3 **一整輪**。外層 2 圈 × 內層 3 圈，大括號最裡面的程式碼總共執行了 6 次。

這就像時鐘：分針（內層）要走完一整圈，時針（外層）才前進一格。

內層的計數變數要用不同的名字，習慣上第一層用 `i`，第二層用 `j`。

### 例子：九九乘法表

來印出乘法表的前三列：

```go
package main

import "fmt"

func main() {
	for i := 1; i <= 3; i++ {
		for j := 1; j <= 9; j++ {
			fmt.Println(i, "x", j, "=", i*j)
		}
		fmt.Println("---")
	}
}
```

執行結果：

```text
1 x 1 = 1
1 x 2 = 2
1 x 3 = 3
1 x 4 = 4
1 x 5 = 5
1 x 6 = 6
1 x 7 = 7
1 x 8 = 8
1 x 9 = 9
---
2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
2 x 4 = 8
2 x 5 = 10
2 x 6 = 12
2 x 7 = 14
2 x 8 = 16
2 x 9 = 18
---
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15
3 x 6 = 18
3 x 7 = 21
3 x 8 = 24
3 x 9 = 27
---
```

注意 `fmt.Println("---")` 是放在內層迴圈的**外面**、外層迴圈的**裡面**，所以每印完一列（內層跑完一輪）才印一次分隔線。把 `i <= 3` 改成 `i <= 9`，就是完整的九九乘法表。

### `break` 只跳出一層

在巢狀迴圈裡用 `break`，只會跳出**最近的那一層**迴圈，外層會繼續跑：

```go
package main

import "fmt"

func main() {
	for i := 1; i <= 2; i++ {
		for j := 1; j <= 3; j++ {
			if j == 2 {
				break
			}
			fmt.Println("i =", i, "j =", j)
		}
	}
}
```

執行結果：

```text
i = 1 j = 1
i = 2 j = 1
```

`j` 一到 2 就跳出內層迴圈，但外層的 `i` 照樣繼續跑下一圈。想一次跳出好幾層的寫法在附錄一會介紹。

## 重點整理

- 迴圈裡可以再放迴圈，叫做巢狀迴圈。
- 外層每跑一圈，內層就從頭跑完整一輪；總次數是兩層次數相乘。
- 內外層的計數變數要用不同名字，習慣用 `i`、`j`。
- `break` 只會跳出最近的那一層迴圈。
