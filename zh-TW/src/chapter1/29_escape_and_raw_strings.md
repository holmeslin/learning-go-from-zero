# 跳脫字元與 raw string

## 本集目標

在字串裡放入換行、Tab、雙引號這些特殊字元，並學會用反引號寫多行字串。

## 正文

### 字串裡想放雙引號怎麼辦？

字串是用雙引號包起來的。如果字串的內容本身也有雙引號，Go 會以為字串提早結束了。這時要在雙引號前面加一個反斜線 `\`：

```go
package main

import "fmt"

func main() {
	fmt.Println("他說：\"你好\"")
}
```

執行結果：

```text
他說："你好"
```

`\"` 的意思是「這是一個普通的雙引號字元，不是字串的結尾」。像這樣用反斜線開頭、代表特殊字元的寫法，叫做**跳脫字元**。

### 常用的跳脫字元

| 寫法 | 代表 |
| --- | --- |
| `\n` | 換行 |
| `\t` | Tab（跳到下一個對齊位置） |
| `\"` | 雙引號 |
| `\\` | 反斜線本身 |

```go
package main

import "fmt"

func main() {
	fmt.Println("第一行\n第二行")
	fmt.Println("姓名\t分數")
	fmt.Println("小明\t90")
	fmt.Println("C:\\Users\\go")
}
```

執行結果：

```text
第一行
第二行
姓名	分數
小明	90
C:\Users\go
```

- `\n` 讓一個 `fmt.Println` 就印出兩行。
- `\t` 會跳到下一個對齊位置，用來排出整齊的表格。
- 想印出一個反斜線，要寫兩個 `\\`，因為單獨一個 `\` 會被當成跳脫字元的開頭。

### raw string：用反引號包起來

如果字串裡有很多反斜線或需要好幾行，一直加 `\` 很麻煩。這時可以改用**反引號** `` ` ``（鍵盤左上角、數字 1 左邊那個鍵）把字串包起來，這叫做 **raw string**（原始字串）：

```go
package main

import "fmt"

func main() {
	fmt.Println(`C:\Users\go`)
	fmt.Println(`他說："你好"`)
	fmt.Println(`第一行
第二行
第三行`)
}
```

執行結果：

```text
C:\Users\go
他說："你好"
第一行
第二行
第三行
```

raw string 裡的內容**完全照字面**：

- 反斜線就是反斜線，`\n` 不會變成換行，而是真的印出 `\` 和 `n` 兩個字。
- 雙引號可以直接寫。
- 可以直接換行，寫成好幾行。

唯一不能放的，是反引號本身。

### 該用哪一種？

- 一般情況：用雙引號。
- 內容有很多反斜線、雙引號，或是需要很多行：用反引號。

## 重點整理

- 雙引號字串裡用反斜線開頭的跳脫字元表示特殊字元：`\n` 換行、`\t` Tab、`\"` 雙引號、`\\` 反斜線。
- 用反引號包起來的是 raw string，內容完全照字面，不處理跳脫字元，而且可以跨好幾行。
- 內容有很多反斜線、雙引號或需要多行時，用 raw string 比較方便。
