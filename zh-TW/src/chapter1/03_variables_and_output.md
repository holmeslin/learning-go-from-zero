# 變數與輸出

## 本集目標

用 `fmt.Println` 印出各種資料，並用 `:=` 建立變數，把資料存起來重複使用。

## 正文

### 用 `fmt.Println` 印東西

上一集我們用 `fmt.Println` 印出了一行字。它的用法是：把想印的東西放進小括號裡，它就會印出來，最後自動換行。

```go
package main

import "fmt"

func main() {
	fmt.Println("你好")
	fmt.Println(42)
	fmt.Println(3.14)
}
```

執行結果：

```text
你好
42
3.14
```

注意「你好」有加雙引號 `"`，數字沒有。用雙引號包起來的是**字串**，也就是一段文字；數字直接寫就好。

`fmt.Println` 一次可以印好幾個東西，用逗號 `,` 隔開，印出來時中間會自動加一個空格：

```go
package main

import "fmt"

func main() {
	fmt.Println("我今年", 18, "歲")
}
```

執行結果：

```text
我今年 18 歲
```

`fmt.Println` 現在當作固定句型照用就好，它背後的原理會在第 2 章（函式）和第 8 章（套件）解釋。

### 變數：幫資料取名字

**變數**就像一個貼了名字的盒子，可以把資料放進去，之後用名字把它拿出來。

```go
package main

import "fmt"

func main() {
	name := "小明"
	age := 18
	fmt.Println(name)
	fmt.Println(name, "今年", age, "歲")
}
```

執行結果：

```text
小明
小明 今年 18 歲
```

`name := "小明"` 的意思是：建立一個叫 `name` 的變數，把 `"小明"` 放進去。`:=` 這個符號就是「建立變數並放入值」。

之後只要寫 `name`，就等於寫 `"小明"`。注意 `fmt.Println(name)` 的 `name` **沒有**加雙引號：加了雙引號就會變成印出 `name` 這四個字母，而不是變數裡的內容。

### 變數名稱的規矩

- 可以用英文字母、數字和底線 `_`，但不能用數字開頭。
- 大小寫不同就是不同的變數，`name` 和 `Name` 是兩個變數。
- Go 的習慣是用英文，多個單字時後面的單字字首大寫，例如 `userName`、`totalScore`。

## 重點整理

- `fmt.Println(...)` 會印出小括號裡的東西並換行；多個東西用逗號隔開，印出時中間有空格。
- 用雙引號包起來的是字串；數字直接寫。
- `名稱 := 值` 會建立一個變數，之後用名稱就能取出裡面的值。
