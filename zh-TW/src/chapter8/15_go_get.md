# `go get` 與相依版本

## 本集目標

了解怎麼使用別人發布的模組、`go.mod` 和 `go.sum` 怎麼記錄它們，以及版本號的意思。

## 正文

本書的範例只使用標準庫，不需要下載任何東西。但實際寫程式時，常常會用到別人寫好、發布在網路上的模組。這一集用概念說明，指令不需要跟著執行。

### 相依套件

如果我們的模組用到了別人的模組，就說我們**相依**（depend on）它，它是我們的**相依套件**（dependency）。

以 Go 團隊維護的 `golang.org/x/text` 模組為例，它提供很多處理文字的套件。要使用它，在自己模組的資料夾裡執行：

```bash
go get golang.org/x/text@latest
```

`go get` 會下載這個模組，並把它記錄到 `go.mod`。`@latest` 代表「最新版」，也可以指定版本，例如 `go get golang.org/x/text@v0.30.0`。

### `go.mod` 多了 `require`

執行之後，`go.mod` 會多出一段：

```gomod
module myapp

go 1.27

require golang.org/x/text v0.30.0
```

（這裡的版本號只是舉例，你實際拿到的會是當時的最新版。）

`require` 這一行記錄：這個模組需要 `golang.org/x/text`，版本是 `v0.30.0`。別人拿到你的程式碼，Go 就會依照這行下載同一個版本，大家用的都一樣。

之後在程式裡就能像標準庫一樣 `import` 它底下的套件，路徑以模組路徑開頭，例如 `golang.org/x/text/width`。

### `go.sum`：確認沒被調包

同時還會多一個 `go.sum` 檔案，內容大概長這樣（雜湊值省略）：

```text
golang.org/x/text v0.30.0 h1:...
golang.org/x/text v0.30.0/go.mod h1:...
```

每一行是某個模組某個版本的**雜湊值**，可以想成檔案的指紋。之後每次下載，Go 都會比對指紋；如果內容和當初不一樣（例如被人動了手腳），就會拒絕使用。

`go.mod` 和 `go.sum` 都要一起保存，不要手動修改 `go.sum`。

### 語意化版本

Go 模組的版本號採用**語意化版本**（semantic versioning），格式是 `v主版本.次版本.修訂版本`，例如 `v1.4.2`：

| 哪個數字變了 | 代表什麼 | 舊程式還能用嗎 |
| --- | --- | --- |
| 修訂版本 `v1.4.2` → `v1.4.3` | 修正錯誤 | 可以 |
| 次版本 `v1.4.3` → `v1.5.0` | 新增功能 | 可以 |
| 主版本 `v1.5.0` → `v2.0.0` | 有不相容的修改 | 不一定 |

兩個特別的規則：

- **`v0` 開頭**代表還在開發中，任何更新都可能不相容。`golang.org/x/text` 目前就是 `v0`。
- **主版本 `v2` 以上**，模組路徑要加上 `/v2`、`/v3`。第 4 集看到的 `math/rand/v2` 就是這個規則：它和舊的 `math/rand` 不相容，所以路徑不同，可以同時存在。

### 常用指令

```bash
go get golang.org/x/text@latest
go get -u ./...
go get golang.org/x/text@none
go mod tidy
```

- `go get 模組@版本`：加入或改成指定版本。
- `go get -u ./...`：把目前用到的相依套件升級到較新的次版本或修訂版本。
- `go get 模組@none`：移除這個相依套件。
- `go mod tidy`：依照程式碼實際 `import` 了什麼，整理 `go.mod` 和 `go.sum`：補上缺的、刪掉沒用到的。改了 `import` 之後跑一下是好習慣。

### 間接相依

如果我們用的模組又相依其他模組，`go.mod` 的 `require` 裡可能出現後面加上 `// indirect` 註解的行，代表「這不是我們直接用的，是相依套件需要的」。這些交給 `go mod tidy` 管理就好。

## 重點整理

- `go get 模組@版本` 下載模組並記錄到 `go.mod` 的 `require`；`@latest` 取最新版，`@none` 移除。
- `go.sum` 記錄每個版本的雜湊值，防止下載的內容被調包；`go.mod`、`go.sum` 都要保存。
- 語意化版本 `v主.次.修訂`：只有主版本變動才可能不相容；`v2` 以上的模組路徑要加 `/v2`。
- `go mod tidy` 依實際的 `import` 整理相依套件。
