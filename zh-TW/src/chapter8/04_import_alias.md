# `import` 與別名

## 本集目標

看懂 `import` 的路徑和套件名稱的關係，並在名稱撞在一起時用別名解決。

## 正文

### 路徑和名字

`import` 後面寫的是套件的**路徑**，程式裡用的則是套件的**名字**。大部分時候，名字就是路徑的最後一段：

| `import` 路徑 | 程式裡使用的名字 |
| --- | --- |
| `"fmt"` | `fmt` |
| `"unicode/utf8"` | `utf8` |
| `"myapp/greet"` | `greet` |

有一個例外要記得：路徑最後一段如果是 `v2`、`v3` 這種版本號，名字取的是前一段。例如 `"math/rand/v2"` 的名字是 `rand`，不是 `v2`。

### 名字撞在一起

標準庫有兩個都叫 `rand` 的套件：`math/rand/v2` 產生一般用途的隨機數，`crypto/rand` 產生密碼學等級、適合拿來做密碼的隨機資料。如果同一個檔案兩個都要用，兩個都叫 `rand` 就會打架。

這時可以在路徑前面幫其中一個取**別名**：

```go
package main

import (
	crand "crypto/rand"
	"fmt"
	"math/rand/v2"
)

func main() {
	dice := rand.IntN(6) + 1
	fmt.Println("骰子點數在 1～6 之間：", dice >= 1 && dice <= 6)

	token := crand.Text()
	fmt.Println("隨機密碼長度：", len(token))
}
```

執行結果：

```text
骰子點數在 1～6 之間： true
隨機密碼長度： 26
```

`crand "crypto/rand"` 的意思是：引入 `crypto/rand`，但在這個檔案裡叫它 `crand`。之後 `rand` 指的是 `math/rand/v2`，`crand` 指的是 `crypto/rand`，各不相干。

隨機數每次都不同，所以我們只印出檢查結果和長度。`rand.IntN(6)` 會回傳 0 到 5 之間的整數；`crand.Text()` 回傳一段 26 個字元的隨機文字。

別名只在這個檔案有效，不會影響其他檔案，也不會改變套件本身。

### 什麼時候用別名

別名的主要用途就是解決名字衝突。如果沒有衝突，就用套件原本的名字，大家讀起來才不會困惑。別名本身的命名，常見的做法是在原名前面加一個字母表示來源，像 `crand`（crypto 的 c）。

### 底線別名

你可能會在別人的程式裡看到這種寫法：

```go,ignore
import _ "image/png"
```

用 `_` 當別名，代表「引入這個套件，但程式裡不會直接用到它的名字」。為什麼要引入一個不用的套件？因為引入時會執行該套件的初始化程式碼，第 6 集講 `init` 函式時會說明。

一般情況下，引入了卻沒使用的套件會造成編譯錯誤，這是 Go 用來保持程式碼乾淨的規則。

## 重點整理

- `import` 寫的是路徑，程式裡用的是套件名字，通常是路徑的最後一段（版本號 `v2` 等除外）。
- 名字衝突時，用 `別名 "路徑"` 幫套件取別名，只在該檔案有效。
- 沒有衝突時不要取別名。
- `import _ "路徑"` 只為了執行套件的初始化，不使用它的名字。
