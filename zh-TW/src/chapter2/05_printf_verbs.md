# `fmt.Printf` 格式動詞

## 本集目標

用 `fmt.Printf` 和格式動詞，精確控制輸出的樣子。

## 正文

`fmt.Println` 很好用，但它會自動在每個值之間加空格，我們沒辦法控制格式。例如想印出「小明今年12歲」中間不要空格，或是把 3.14159 只印到小數點後兩位，就需要 `fmt.Printf`。

### 第一個 `Printf`

```go
package main

import "fmt"

func main() {
	name := "小明"
	age := 12
	fmt.Printf("%s今年%d歲\n", name, age)
}
```

執行結果：

```text
小明今年12歲
```

`Printf` 的第一個值是一個「格式字串」，裡面的 `%s`、`%d` 叫做**格式動詞**，它們是「預留的空位」。後面的值會照順序填進去：`name` 填進 `%s`，`age` 填進 `%d`。

注意最後的 `\n`。`Println` 會自動換行，`Printf` **不會**，要換行就得自己加 `\n`（第 1 章學過的跳脫字元）。

### 常用的格式動詞

| 動詞 | 用途 |
| --- | --- |
| `%v` | 任何值，用預設格式印出 |
| `%d` | 整數 |
| `%s` | 字串 |
| `%f` | 小數（浮點數） |
| `%.2f` | 小數，捨入顯示到小數點後 2 位 |
| `%q` | 加上雙引號的字串 |
| `%T` | 值的型別 |
| `%%` | 印出一個 `%` 符號，不需要對應的值 |

一次看看它們的效果：

```go
package main

import "fmt"

func main() {
	score := 87
	price := 3.14159
	word := "Go"
	ok := true

	fmt.Printf("%v %v %v %v\n", score, price, word, ok)
	fmt.Printf("%d\n", score)
	fmt.Printf("%s\n", word)
	fmt.Printf("%f\n", price)
	fmt.Printf("%.2f\n", price)
	fmt.Printf("%q\n", word)
	fmt.Printf("%T %T %T %T\n", score, price, word, ok)
	fmt.Printf("達成率 %d%%\n", score)
}
```

執行結果：

```text
87 3.14159 Go true
87
Go
3.141590
3.14
"Go"
int float64 string bool
達成率 87%
```

幾個值得注意的地方：

- `%v` 什麼都能印，不知道用哪個時就用它。
- `%f` 預設印到小數點後 6 位；`%.2f` 會把浮點值捨入並顯示到小數點後 2 位。這只是顯示格式，不保證符合金額的十進位捨入規則。
- `%q` 會幫字串加上雙引號，想看清楚字串前後有沒有多餘的空白時很方便。
- `%T` 印的是**型別**，不是值。不確定某個變數是什麼型別時，可以用它檢查。
- `%` 在格式字串裡有特別意義，想印出 `%` 本身要寫兩個 `%%`，而且不用多給一個值。上面的 `%d%%` 只需要 `score` 這一個值。

例如 `1.125` 正好在 `1.12` 和 `1.13` 的中間，而且能用二進位浮點數精確表示，但 `fmt.Printf("%.2f\n", 1.125)` 印出的是 `1.12`，不是 `1.13`。所以不能把 `%.2f` 當成金額「逢五進位」的規則。

### 動詞要和值對得上

在本集這些寫法中，除了不需要值的 `%%`，每個格式動詞都要對上一個值，動詞的種類也要和值的型別相符（例如 `%d` 配整數）。寫錯的話，Go 雖然還是能編譯，但印出來會是一串奇怪的東西。好消息是 `go vet` 會幫你檢查出這類錯誤，第 8 章會介紹它。

## 重點整理

- `fmt.Printf("格式字串", 值1, 值2, ...)`：值會依序填進需要值的格式動詞；`%%` 不消耗值。
- 常用動詞：`%v` 任何值、`%d` 整數、`%s` 字串、`%f` 小數、`%.2f` 兩位小數、`%q` 帶引號字串、`%T` 型別、`%%` 百分比符號。
- `Printf` 不會自動換行，要自己在結尾加 `\n`。
- 除了 `%%`，本集的格式動詞數量與種類要和後面的值對得上。
- `%.2f` 是把浮點值捨入顯示到小數點後 2 位，不是金額的十進位逢五進位規則。
