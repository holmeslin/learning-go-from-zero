# 簡單函式

## 本集目標

學會自己定義函式，把一段程式碼取個名字，需要時再呼叫它。

## 正文

### 其實你一直在用函式

從第一個程式開始，我們就一直在寫 `func main() { ... }`。`main` 就是一個**函式**（function）：一段取了名字的程式碼。Go 程式啟動時，會自動執行名叫 `main` 的函式。

而 `fmt.Println(...)` 則是在**呼叫**別人寫好的函式：名字叫 `Println`，放在 `fmt` 套件裡。

現在，我們要自己寫函式了。

### 定義和呼叫

```go
package main

import "fmt"

func sayHello() {
	fmt.Println("哈囉！")
	fmt.Println("歡迎學 Go")
}

func main() {
	sayHello()
	sayHello()
}
```

執行結果：

```text
哈囉！
歡迎學 Go
哈囉！
歡迎學 Go
```

拆開來看：

- `func sayHello() { ... }` **定義**了一個函式。`func` 是關鍵字，`sayHello` 是名字，後面的 `()` 先照寫，下一集會用到，大括號裡是函式要做的事。
- `sayHello()` 是**呼叫**這個函式：程式跳進 `sayHello` 裡，把裡面的程式碼從頭執行到尾，然後回到呼叫的地方繼續往下。

我們呼叫了兩次，所以兩行字印了兩遍。同一段程式碼只要寫一次，想用幾次就呼叫幾次。

### 執行順序

函式寫在檔案的哪裡都可以，`sayHello` 放在 `main` 的上面或下面都沒關係。程式**永遠從 `main` 開始**，定義了卻沒被呼叫的函式不會執行：

```go
package main

import "fmt"

func main() {
	fmt.Println("開始")
	step()
	fmt.Println("結束")
}

func step() {
	fmt.Println("  正在執行 step")
}

func unused() {
	fmt.Println("我不會被印出來")
}
```

執行結果：

```text
開始
  正在執行 step
結束
```

`unused` 沒有被呼叫，所以它裡面的那行永遠不會印出來。（跟變數不同，函式沒用到不會造成編譯錯誤。）

### 為什麼要寫函式？

1. **不用重複寫**：同樣的事情寫成函式，呼叫就好。
2. **好讀**：一段程式取了好名字，例如 `printMenu()`，看名字就知道它在做什麼，不用讀裡面每一行。
3. **好改**：要修改那段邏輯時只改一個地方。

函式的名字和變數一樣，通常用小寫開頭、每個新單字大寫（例如 `printMenu`）。

## 重點整理

- 函式是一段取了名字的程式碼；`main` 也是函式，程式從它開始執行。
- 用 `func 名字() { ... }` 定義函式，用 `名字()` 呼叫它。
- 呼叫時，程式會執行完函式裡的內容，再回到呼叫處繼續往下。
- 只有被呼叫的函式才會執行，函式寫在檔案中的位置不影響執行順序。
