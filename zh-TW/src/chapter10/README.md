# `context`

第 9 章我們學會開 goroutine、用 channel 傳話，也知道 goroutine 不收尾會洩漏。可是真實的程式常常是一層呼叫一層：處理一個網路請求，要查資料庫、再呼叫別的服務，每一層可能又開了自己的 goroutine。使用者中途關掉網頁、或是整件事已經超過時間了，要怎麼一口氣通知底下所有人「別做了」？

這一章要學的 `context` 套件，就是 Go 對這個問題的標準答案。它把「取消訊號」「截止時間」和「少量跟這次請求有關的資料」打包成一個值，沿著函式呼叫一路往下傳。之後的 HTTP 伺服器、資料庫操作，幾乎每個函式的第一個參數都是它，所以這章是進入實戰章節前的必修課。
