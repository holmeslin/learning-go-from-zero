# 並行

到目前為止，我們的程式都是一行接一行、一次只做一件事。可是真實世界的程式常常要「同時」處理很多事：網頁伺服器要同時服務好幾個使用者，下載工具要同時抓好幾個檔案，等網路回應的時候也不該讓整支程式乾等。

這一章要學 Go 最有名的功能：**並行**（concurrency）。我們會用 goroutine 讓好幾段程式同時跑，用 `sync` 套件保護大家共用的資料，用 channel 在 goroutine 之間傳遞資料，最後學會怎麼避開死結和 goroutine 洩漏，並用 `testing/synctest` 測試和時間有關的並行程式。並行程式的錯誤常常不是每次都會出現，所以這一章也會特別花時間講怎麼發現和預防這些問題。
